# Commercial Proposal Generator

Веб-приложение для создания коммерческих предложений (КП): шаблоны → редактирование → PDF.
Используется реальными клиентами строительно-отделочной компании.

## Возможности

- Шаблоны КП с разделами и позициями, версионирование при реальном изменении (не на каждый save)
- Экспорт в PDF под фирменный образец заказчика (реквизиты, разделы, подписант), live-превью без генерации файла
- Управление пользователями и доступом (`user`/`admin`), без публичной регистрации
- Справочник цен: приём позиций из разных источников в единый каталог, автоматическая
  категоризация и нормализация названий через локальную LLM

## Инженерные решения

- **Stateless-аутентификация с мгновенным отзывом доступа.** JWT без таблицы сессий, но
  `role`/`is_active` перечитываются из БД на каждый запрос — деактивация пользователя действует
  сразу, без отзыва конкретных токенов.
- **Версионирование по реальному диффу.** Новая версия КП создаётся только при содержательном
  изменении; восстановление старой версии переключает указатель, а не дублирует запись.
- **LLM-нормализация каталога цен («Библиотекарь»).** Вольные названия работ из разных
  источников приводятся к единому канонической форме и категории через локальную модель с
  grammar-constrained JSON-выводом, чтобы одинаковые по сути позиции не плодили дубли-синонимы;
  дедупликация — на уровне БД по хешу строки.
- **Проектирование через формальное ревью.** Архитектура автоматизированного приёма документов в
  каталог (внешний оркестратор → та же точка входа `ingest`) прошла несколько раундов независимого
  технического ревью до начала сборки — с явной моделью состояний, обработкой гонок и
  восстановлением после сбоя.

## Быстрый старт

```bash
# Backend (порт 3000) — запускать первым, дать подняться, затем frontend
cd backend && npm install && npm run dev

# Frontend (порт 3001)
cd frontend && npm install && npm run dev
```

Backend требует PostgreSQL и `.env` (см. `backend/.env.example`). Миграции — `npm run migrate` в
`backend/`. Подробная пошаговая инструкция с нуля (системные зависимости, база данных) —
[SETUP.md](SETUP.md).
